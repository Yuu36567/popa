# Random Data Generator
простой учебный проект на питоне который генерирует случайные данные (имена адреса) с помощью библиотеки
## описание
скрипт создает экземпляр генератора 'faker' с русской локалью и выводит в консоль случайное имя и адрес

Цель: Научиться получать код с GitHub для изучения или доработки.

1.  Найдите на GitHub любой простой и открытый репозиторий (например, с игрой "Змейка" или "Крестики-нолики").

3.  В терминале выполните команду `git clone <скопированный-url>`.

Критерий успеха: Чужой проект успешно скопирован к вам на компьютер и запускается.

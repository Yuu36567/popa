# Random Data Generator
простой учебный проект на питоне который генерирует случайные данные (имена адреса) с помощью библиотеки
## описание
скрипт создает экземпляр генератора 'faker' с русской локалью и выводит в консоль случайное имя и адрес

Задание 1: «Знакомство с GitHub CLI»
Цель: Научиться работать с GitHub из командной строки.
Задача:
1.  Установите GitHub CLI (`gh`).
2.  Выполните команду `gh auth login` и авторизуйтесь.
3.  Создайте новый репозиторий прямо из терминала: `gh repo create my-new-project --public --clone`.
4.  Перейдите в папку репозитория и добавьте туда файл `README.md`.
5.  Выполните команды `git add .`, `git commit -m "initial commit"`, `git push`.
Критерий успеха: Новый репозиторий создан на вашем GitHub-аккаунте и содержит файл `README.md`.
